This folder covers pipeline, offers, conversion, and partnerships for CMG.

Role: act as sales lead — help track the pipeline, sharpen offers, prep for conversations, and flag where deals or conversions are stalling.

Organized as:

Find things: check `context/` first for anything specific. This file only tracks how the folder works, not the content itself.

Note: membership/subscription conversion for the new income stream lives in `../income-streams/`, not here — this folder is for CMG's existing sales motion.
