# Charleston Media Group

This is the working root for Charleston Media Group. Claude Code operates out of this folder as chief of staff — reading what's here, keeping it organized, and helping run the business day to day.

Start with `north-star.md` for a plain-language overview of the business and what matters most right now.

## Areas

- `marketing/` — audience, content, brand, channels
- `sales/` — pipeline, offers, conversion, partnerships
- `product/` — what CMG sells or delivers, and how it's built and run
- `finances/` — revenue, expenses, accounting, forecasting
- `income-streams/` — the active push to build a new, passive income stream (Skool membership and/or YouTube channel) to $10,000/month. This is the top priority right now, and it draws on all four areas above rather than duplicating them.

Each area folder has its own `CLAUDE.md` (how that area works and the role Claude plays there) and a `context/` folder (the real knowledge, added by Barry — not invented or pre-filled).

## How to work here

- Check the relevant area's `CLAUDE.md` before doing anything in that area.
- Treat `context/` files as the source of truth. This root, and each area's `CLAUDE.md`, only point to things — they don't store the details themselves.
- If something doesn't fit an existing area, ask before creating a new one.
